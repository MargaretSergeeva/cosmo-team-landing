# Лог решений

Дата старта: 2026-10-21. Новые решения добавляем сверху.

## 2026-10-21

**Бизнес-идея.** IT- и digital-консалтинг: аудит стека, экономия, кастомные решения, внедрение ИИ.
Команда: бизнес и продажи, разработка и DevOps, безопасность, UI/UX.

**Сегмент.** Русскоязычные предприниматели в Германии / DACH (не только из РФ: Украина, Казахстан, Беларусь, Прибалтика, Израиль, поздние переселенцы). Это точка входа, а не единственный рынок.
Риск: санкции ЕС. Для каждого клиента проверяем владельцев (KYC).

**Оффер.** IT-Check за 2 недели по фиксированной цене (ориентир 1 500–2 500 €, финальная цена не определена). Стоимость засчитывается при заказе внедрения. Воронка: Знакомство → IT-Check → Внедрение → IT-отдел на аутсорсе.

**Проверка спроса.** До затрат проводим 10–15 интервью по скрипту (`interview-script.md`).

**Сайт.** Лендинг на RU/EN/DE с переключателем-флажками, стиль AI Observatory (тёмная тема). Рабочее название — Cosmo Team (не окончательное).
- Мок: Claude Design canvas «IT-Check Landing».
- Сайт: этот репо, GitHub Pages, `noindex`, плашка «Черновик».
- В немецкой версии обращение на «Sie».

**Квиз.** 11 вопросов, «Бесплатный тест за 3 минуты», свёрнут за кнопкой, подсчёт в браузере без отправки данных. Подробности в `quiz.md`.

**Юрформа.** На старте — индивидуальная регистрация (Gewerbe/Freiberufler) и субподряд внутри команды; UG после подтверждения спроса. Через компании знакомых не работаем. См. `legal-notes.md`.

**Задачи.** Ведём в YouTrack (временно, пока не выбран PM tool). Копия в `backlog.md`.
