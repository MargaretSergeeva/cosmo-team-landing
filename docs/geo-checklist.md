# Чек-лист: видимость в поиске и у ИИ (SEO + GEO)

Цель: чтобы Google, Bing, ChatGPT, Perplexity и Google AI Overviews находили сайт и рекомендовали нас по запросам вроде «IT-консультант на русском в Берлине». Относится к задаче 4.

## Технически (до запуска)
- [ ] Весь текст есть в HTML без JavaScript (статичные страницы на каждый язык)
- [ ] Отдельные URL на каждый язык: `/ru/`, `/de/`, `/en/`, с `hreflang` и `x-default`
- [ ] Убрать `noindex`
- [ ] `robots.txt` разрешает Googlebot, Bingbot, GPTBot, OAI-SearchBot, PerplexityBot, ClaudeBot, Google-Extended
- [ ] `sitemap.xml` со всеми языковыми версиями
- [ ] Разметка schema.org (JSON-LD): `ProfessionalService`, `Organization`, `FAQPage`
- [ ] Уникальные `<title>` и `meta description` на каждом языке
- [ ] Подключены Google Search Console и Bing Webmaster Tools, отправлен sitemap
- [ ] Быстрая загрузка: Lighthouse ≥ 90, без тяжёлых скриптов
- [ ] Опционально: `llms.txt` с кратким описанием компании (стандарт пока не устоялся, эффект не гарантирован)

## Контент
- [ ] Блок FAQ с прямыми формулировками реальных запросов (RU и DE)
- [ ] Конкретика: город, языки, отрасли, цена, сроки
- [ ] Список ключевых запросов на RU/DE/EN (собрать из интервью и Google/Bing)
- [ ] 3–5 статей-гайдов: NIS2 для малого бизнеса, EU AI Act простыми словами, как сократить расходы на SaaS, DSGVO-чек для малого бизнеса
- [ ] Страницы кейсов после первых пилотов

## Упоминания вне сайта
- [ ] Google Business Profile и Bing Places
- [ ] LinkedIn-страница компании и профили команды со ссылкой на сайт
- [ ] Каталоги консультантов, партнёрские Steuerberater, IHK
- [ ] Отзывы и кейсы клиентов (с их согласия)
- [ ] Выступления и посты в русскоязычных бизнес-сообществах

## Как проверять
- Раз в месяц задавать ChatGPT, Perplexity и Google 10 целевых запросов и записывать, упоминают ли нас
- Смотреть показы и клики в Search Console и Bing Webmaster Tools
