# Сайт: технические требования

Для разработчика. Текущий `index.html` — прототип: тексты подставляются через JS, шрифты грузятся из Google Fonts, форма никуда не отправляет. Для продакшена его нужно пересобрать. Ниже требования и рекомендуемый стек; финальные решения за тобой.

## Требования
1. **Контент в HTML без JS.** ИИ-краулеры (GPTBot, PerplexityBot и др.) часто не выполняют JavaScript. JS нужен только для интерактива: переключатель языка, квиз.
2. **Отдельные URL на каждый язык:** `/ru/`, `/de/`, `/en/`, взаимные `hreflang` и `x-default` (вероятно, `/de/`). Переключатель-флажки — это ссылки на соответствующие страницы, а не подмена текста.
3. **DSGVO по умолчанию:**
   - шрифты хостим сами (Space Grotesk, Inter, JetBrains Mono): подключение Google Fonts с CDN в Германии уже приводило к штрафам;
   - никаких сторонних запросов без согласия;
   - аналитика без cookie (Plausible, Matomo без cookie или Umami), тогда баннер согласия не нужен;
   - хостинг и обработка формы в ЕС.
4. **SEO/GEO:** см. `geo-checklist.md` (schema.org JSON-LD, sitemap, robots.txt, meta на каждый язык).
5. **Производительность и доступность:** Lighthouse ≥ 90 по всем пунктам, контраст по WCAG AA, фокус-стейты, реальные `<button>`/`<a>`/`<label>`.
6. **Обязательные страницы:** Impressum и Datenschutzerklärung на DE (и ссылки из футера на всех языках).

## Рекомендуемый стек
- **Astro** со встроенным i18n-роутингом: статичный HTML, «острова» для квиза, контент в Markdown/JSON
- Тексты из текущего `index.html` (объекты `L` и `Q`) вынести в `src/i18n/{ru,de,en}.json`
- Квиз — один island-компонент (vanilla или Preact), логика подсчёта та же (`docs/quiz.md`)
- Дизайн-токены AI Observatory → CSS-переменные (уже есть в `index.html`)

## Форма → CRM
- Отправка через serverless-функцию на EU-хостинге, ключ CRM только на сервере
- Обязательный чекбокс согласия со ссылкой на Datenschutz
- Защита от спама без reCAPTCHA (honeypot или Friendly Captcha / Cloudflare Turnstile)
- CRM пока не выбрана (задача 7), поэтому функцию делаем с адаптером под конкретную API

## Хостинг и деплой
- Варианты с EU-регионом: Netlify / Vercel (EU-функции), Cloudflare Pages, Hetzner + статика
- Деплой из `main` через GitHub Actions, превью на pull requests
- Домен (задача 6) с HTTPS и редиректом `/` на язык по `Accept-Language`, с сохранением выбора пользователя

## Метрики (связано с задачей 10)
Событийная воронка: просмотр → старт квиза → результат квиза → клик «Заказать IT-Check» → отправка формы.
